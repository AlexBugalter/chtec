# Участие в разработке

Для разработки нужен Python 3.11+; основная проверенная платформа — Windows.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check chtec tests
```

Автоматическим тестам не нужна загруженная LLM. HTTP-тесты используют временные
серверы на `127.0.0.1`, Qt-тесты — offscreen. Тесты Windows-процессов проверяют
только специально созданные экземпляры.

Для ошибки приложите шаги воспроизведения, версию Python/ОС, выбранную систему
и обезличенный пример. Не публикуйте ключи, личные документы, приватные пути
или журналы без проверки содержимого. Предпочтительны синтетические изображения.

Для изменений геометрии проверяйте выделение в обоих направлениях, повороты,
повторяющиеся слова, отмену и сохранение проекта. Для нового формата добавляйте
проверку импорта/экспорта и отрицательные сценарии.
